# Resume-Ready Project Entry

## Microsoft Entra ID IAM Foundation & JML Lab

- Built a Microsoft Entra ID lab with cloud user identities, department security groups, and job-specific entitlement groups using a consistent enterprise-style naming convention.
- Implemented least-privilege RBAC by separating standard and privileged accounts, assigning the User Administrator role, configuring Microsoft Authenticator MFA, and validating both permitted and restricted administrative actions.
- Executed Joiner-Mover-Leaver workflows by provisioning new-hire access, updating identity attributes and removing obsolete access during department transfers, and disabling accounts, revoking sessions, and removing group access during offboarding.
- Performed delegated password resets, security-group administration, access validation, and lifecycle deprovisioning while documenting the project for a GitHub IAM portfolio.
